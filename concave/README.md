# L-shaped reconstruction: adaptive unknown-cut search

第三頁從**單一總 sinogram** 尋找切線，再重建兩個候選凸片。不提供真實切線、個別 sinogram 或 L 型頂點給搜尋器。新版修正「粗網格全部失敗就停止」；最佳指**已評估候選中，全資料相對 L₂ 誤差最小**，不是全域最優。

重要限制：

- 未旋轉三例選中 y=-0.2：這條真實可行切線**剛好在通用固定網格上**，不是單靠自適應細化的成績。它沒有被寫進搜尋器，但這些案例有網格對齊優勢。
- 旋轉案例的粗網格沒有相容候選；新版仍繼續細化，最終找到候選，驗證了修正的失敗路徑。但此例真體凸性仍失敗：缺口面積約 0.008770，外包絡漏出真值距離約 0.011500（舊版約 0.001807）。**資料擬合改善不代表所有幾何指標都改善。**
- 16 角度的 100% IoU 只對 257² 評估網格成立；取樣邊界距離仍約 0.002970，並非精確重建。
- 所有案例是開發測試，不是獨立測試集；沒有 FBP／SIRT／TV 對照，也未證明普遍精度或速度優勢。需要細化的案例可能明顯較慢。

## 新版如何找切法

候選切線寫成 x cos φ + y sin φ = s。搜尋只改 φ、s；每一條切線都呼叫同一個幾何重建器。

1. **固定粗搜尋。** 已知視野為 [-1.8,1.8]²；12 個法向量方向（每 15°），各取 s=-1.6,-1.4,…,1.6，共 204 個候選。粗網格不再依「不同角度數產生的外包絡」改動。這是有限搜尋範圍，並未覆蓋所有可能切法。
2. **保留兩類起點。** 一類是已通過數值檢查、全資料誤差小的候選；另一類是雖有矛盾、但違反弦長或包含限制較少的候選。各最多四個，並用參數距離避免起點全擠在同處。另保留最多兩個尚不能形成內框的候選。
3. **持續細化。** 各起點附近測 3×3 個方向／位置組合；每層步幅減半，最多 12 層。**沒有相容粗候選也要做這一步。** 矛盾量只是啟發式排序，並不是某個參數區域的嚴格下界，不能據此證明整區不可能。
4. **多角度的額外起點。** 超過 8 個方向且粗搜尋未達資料誤差目標時，均勻挑 8 列量測做同樣搜尋。把子集搜尋過程中改善的切法轉交全資料，**重新初始化、檢查並評分**。子集相容不等於全資料相容，子集分數不參與最終排名。
5. **保留歷來最佳。** 通過檢查的切法，以其兩片中點聯集的全資料相對 L₂ 誤差排名。不讀 IoU、真實形狀或已知正確切線。候選越多，已找到的最低分不會倒退，但這不保證不同角度數之間的誤差單調。
6. **停止條件。** 完成粗網格／某細化層後，若資料相對誤差 ≤ 10⁻⁷ 就停止；否則最多 12 層或每次搜尋 1,500 個候選。子集另有相同預算，計算次數會分開記錄。未找到候選稱「預算內搜尋失敗」，不稱「無解」。

`stages` 記錄階段成果，`history` 記錄每次最佳分數改善，`seedSearch` 記錄子集來源，`totalEvaluations` 包含子集成本。這是有限預算的多起點搜尋，**不是分枝定界法、不是全域最優演算法，也沒有唯一性保證**。

## 每個候選如何重建與被排除

1. 用總投影最外側正值 detector 的外鄰點建全域外包絡，再以候選線裁成兩個外框。假設真體在切線兩側分別凸。
2. 對每條射線，設各片內、外弦長為 qᵢ、uᵢ，測得總長 g。本片下界為 max(qᵢ,g−Σ其他 uⱼ,0)，上界為 min(uᵢ,g−Σ其他 qⱼ)。
3. 外弦為 [a,b]、下界為 L 時，凸片必含 [b−L,a+L]（非空才用）。取各必存線段的凸包，先做兩次內框生成。沒有二維內框標 `unresolved`，不當成不可能。
4. 每輪固定內框，用弦長上界及凸性排除外部點，再擴充內框；每候選最多三輪。檢查 Σqᵢ≤g≤Σuᵢ 及內框包含於外框；違反超過 2×10⁻⁷ 標 `contradiction`。這是浮點數值檢查，不是機器認證。
5. 輸出兩片 Minkowski 中點的聯集，重新投影評分。數值異常單獨標 `numerical-error`；候選切線若重合量測射線則標 `boundary-ray` 略過，避免沿共享邊雙重計數。

線長模擬與輸出評分先合併相交區間再計聯集長度，不盲目相加。`engine.js` 沒有匯入 `phantom.js`，只接收 total、angles、detector。真值只進入模擬與最後評估。長度迴圈可接受多片，但**搜尋與本次實測只切兩片**。

## 實驗規格與數字意義

密度 0/1、無雜訊。91 個 detector，sₖ=(k−45)×0.04+0.013，量測角度均勻覆蓋 [0,π)。L 型頂點為 (-1,-0.8)、(1,-0.8)、(1,-0.2)、(-0.35,-0.2)、(-0.35,1)、(-1,1)；旋轉例旋轉整體 22.5°。所有新舊比較使用相同資料。

- 資料誤差：||R(output)−g||₂/||g||₂，不使用真值。
- IoU：257×257 網格的交集／聯集，只供事後評估。
- 邊界距離：每條邊間隔至多 0.005 取樣，算雙向點到另一集合的最大距離；不是精確聯集 Hausdorff 距離或嚴格上界。
- 真體凸性：切後各片凸包面積減去原面積；缺口 ≤10⁻⁹ 才通過，只是事後數值診斷。
- 外包絡漏出真值：切後真值各頂點到對應外框的最大距離。正值代表包含關係失效。
- 內外距離半值：只有真實分片凸且內外包含成立才可援用原條件性定理。自動選切線本身不驗證這些假設；尤其不可把旋轉例的數值當已成立的真體誤差界。

## 重現

在儲存庫根目錄執行：

```sh
node --test tutorial/geometry.test.cjs concave/engine.test.cjs
node concave/run.cjs 4 0
node concave/run.cjs 8 0
node concave/run.cjs 8 22.5
node concave/run.cjs 16 0
node concave/compare.cjs
```

各 `result-*.json` 包含輸入、搜尋軌跡、最佳包絡、事後評估、時間及引擎 SHA-256。`oracleCutDiagnostic` 額外測已知真實切線，只是診斷，從未加入搜尋或未知切線排名。`compare.cjs` 檢查保存結果的引擎版本與資料，重新執行舊版後產生對照。

網站用靜態伺服器開啟 `concave/`。可以重跑背景搜尋、切換四個案例與五個步驟、查看更新輪數／射線／任意候選、查看階段表與匯出 JSON。

下一步是獨立的旋轉、位移與尺寸變化測試，以及切割誤差對包含關係的分析。不能把這四例推論成任意凹形都能重建。

# L-shaped reconstruction with an unknown cut

第三頁是實際可重算的未知切線先導實驗。原始輸入只有一份總 sinogram，切線由候選搜尋決定；真值只進入模擬與最後評估。

## 已執行結果

日期：2026-09-29。密度 0/1，無雜訊，視野 [-1.8,1.8]²，91 個 detector，s_k=(k−45)×0.04+0.013，角度均勻覆蓋 [0,π)。L 型頂點依序是 (-1,-0.8)、(1,-0.8)、(1,-0.2)、(-0.35,-0.2)、(-0.35,1)、(-1,1)。旋轉案例將整個 L 型旋轉 22.5°。

**這些結果顯示高精度近似的可能性，但沒有建立未知切割下的真體包絡保證。** 特別是 8 角度案例，所選切法的一片仍有約 0.001883 的非凸缺口面積，外包絡漏出真值的最大頂點距離約 0.001245；因此不能把畫面的內外距離半值 0.007837 當成已證明的真體誤差上界。

16 角度時，204 個粗候選沒有一個通過檢查，局部细化無從開始。另把真實切線 x=-0.35 提供給引擎，可得到約 1.54e-8 的資料誤差；該結果只診斷搜尋限制，明確排除於未知切線成果之外。更多量測能排除不準確候選；本版需要改善搜尋，而非主張「角度越多越差」。

## 演算法與資料隔離

1. 用總投影的最外側正值 detector 加一格建立全域外包絡。
2. 在 12 個法向量方向（每 15°）搜尋切線。每個方向在外包絡投影區間內均分取 17 個位置，共 204 個粗候選。切線參數不使用 L 型頂點。
3. 用兩個半平面裁開全域外包絡，**假設真體在兩側分別凸**。沿切線重合的量測射線可能重複計算共有邊，本版略過這類候選並記錄 boundary-ray。
4. 對任意片 i，以其內、外弦長 q_i、u_i 推得下界 max(q_i,g−Σ其他 u_j,0) 及上界 min(u_i,g−Σ其他 q_j)。由外弦 [a,b] 及下界 L 產生必存區間 [b−L,a+L]；取凸包，先做兩次內框生成。無二維內框則標為 unresolved，不能直接斷定切法錯誤。
5. 外部排除使用第二頁同一組幾何函式。每輪固定內框裁外框，再擴充內框，共最多三輪。每轮檢查 Σq_i≤g≤Σu_i 與內框是否落在外框；超過 2e-7 容差視為數值矛盾。數值異常另行記錄，不等同數學不可行。
6. 在未發現矛盾的候選中，按中點輸出的總投影相對 L₂ 誤差排序。保留最多八個，取前三個附近做三層局部細化；方向及位移步幅每層除以三。不使用 IoU、真值距離或真實切線選答案。

engine.js 只接收 data.total、data.angles、data.detector，沒有匯入 phantom.js。UI 的真值顯示選項不會參與重建。forward() 先合併線段再計聯集長度，避免模擬或評估時重複計算共享邊界。單片幾何操作重用 ../tutorial/geometry.js；長度傳播迴圈已寫成多片形式，但**切線搜尋與本次實測仍只有兩片**。

## 輸出數字如何解讀

- 總投影相對誤差：||R(output)−g||₂ / ||g||₂，僅用量測資料。
- IoU：257×257 網格上的交集像素數／聯集像素數，只在評估端使用真值。
- 邊界距離：每條邊間隔至多 0.005 取樣，計兩向「點到另一集合」最大距離。這不是精確聯集 Hausdorff 距離，也不當作嚴格上界。
- 真體凸性：切後的真值各片，其凸包面積減去原面積。缺口面積大於 1e-9 就不通過。判斷僅供事後診斷，不進入搜尋。
- 外包絡漏出真值：將真值原始凸片按候選線裁切，檢查各頂點到對應外包絡的距離。正值揭露包含關係失效。
- 內外距離半值：只有真實分片凸，且內外包含關係成立時，才可套用前面的條件性誤差定理。本次所選切法均未通過真體凸性檢查。

凸分解可能不唯一，有限資料也可能容許不同形狀；本實驗不宣稱找出唯一切法、不宣稱任意非凸體重建，也沒有與 FBP/SIRT/TV 比較。沒有按真值挑選切法，但案例與設定是開發用先導證據，並非獨立最終測試。

## 重現與使用

在網站根目錄啟動靜態伺服器，開啟 concave/。頁面先顯示已保存的實測結果；「重新搜尋切線」會在背景執行相同引擎。可切換四個案例、五個解說步驟、輪數、投影方向，以及檢視任意候選。

從儲存庫根目錄執行：

    node --test tutorial/geometry.test.cjs concave/engine.test.cjs
    node concave/run.cjs 8 0
    node concave/run.cjs 4 0
    node concave/run.cjs 8 22.5
    node concave/run.cjs 16 0

每個 result-*.json 包含輸入、真值（評估用）、所有候選摘要、最佳候選的各輪包絡、評估數字、計算時間及引擎 SHA-256。各案例應各自重跑；時間受裝置與同時執行工作影響，不是速度優勢證據。

下一步應研究切割誤差如何影響包含關係，以及無相容粗候選時如何繼續細化，不能直接把條件性定理套到自動選出的切線。

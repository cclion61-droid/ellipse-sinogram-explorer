# Ellipse Radon Lab

一個不使用 FBP 的互動式 Radon transform 視覺化工具。可以新增、隱藏、移動、旋轉與縮放多個橢圓，並即時觀察對應的 sinogram。

## 第三頁：L 型未知切線實測

開啟 **[concave/index.html](concave/index.html)**：從單一總 sinogram 搜尋切線、查看兩片包絡更新、重新投影核對，並比較四個實測案例。新版使用固定粗網格、多起點矛盾引導細化與子集起點全資料重驗；16 角度已找到候選，8 角度 L 型網格 IoU 約 99.990%。未旋轉案例有網格對齊優勢；旋轉案例仍未通過真體凸性檢查，不能套用原來的包絡誤差保證。保留舊版搜尋與新舊比較，不宣稱全域最優。可在瀏覽器重算、檢視候選與搜尋階段、匯出紀錄；詳見 [實驗說明](concave/README.md)。

## 新增：雙凸體重建逐步教學

開啟 **[tutorial/index.html](tutorial/index.html)**，從雙橢圓產生的總 sinogram 出發，用 10 個步驟看懂端點、外包絡、弦長下界、必存內部線段、外部點、凸性排除，以及最後的包絡中點。

- 預設中文解說，沒有外部套件，可離線開啟。
- 可選 4／8／16 角度，切換射線、開關真值疊圖、回放三輪更新。
- 橢圓只用來製造資料；重建程式只接收一張總 sinogram，不知道橢圓參數。
- 真實計算的裁切附局部放大，另有初始化失敗案例。
- 詳細算法、限制、檔案索引與測試方法：**[教學 README](tutorial/README.md)**。

在網站根目錄執行幾何測試（Node.js 18 或更新版本）：

```bash
node --test tutorial/geometry.test.cjs
```

## 兩種資料模型

- **二值聯集**：物體是所有橢圓的聯集，重疊區仍然等於 1。程式先求每條投影線與各橢圓的交線區間，再合併重疊區間並計算聯集長度。
- **密度加法**：每個橢圓具有密度 `ρ`，每條投影的值是各橢圓截線長度乘密度後的總和。重疊區密度會相加。

Sinogram 的每個取樣值都由直線與橢圓的二次方程解析求交得到，不經過影像離散化，也不使用 FBP。

## 操作

1. 拖曳橢圓中央的黃色點移動中心。
2. 拖曳兩個外側控制點改變半軸；長軸控制點同時決定旋轉角。
3. 左側可以新增、隱藏、選取或刪除橢圓，並用滑桿精確調整參數。
4. 切換「二值聯集」與「密度加法」，比較重疊時的 Radon 資料。

## 本機執行

這是無相依套件的靜態網站。在此資料夾啟動任一靜態檔案伺服器即可，例如：

```bash
python -m http.server 4173
```

然後開啟 `http://localhost:4173`。
